\# LAB2 — Cat and Mouse



Объектно-ориентированная реализация игры «Кошки-мышки» на C#.



\## Описание



Кот и мышь находятся на замкнутом в круг поле из `N` клеток (нумерация с 1 до `N`).

Игроки по очереди двигаются по командам из входного файла. Если после хода

кот оказывается в той же клетке, что и мышь — мышь поймана, игра завершается.

Если команды закончились, а мышь не поймана — она сбежала.



\## Структура проекта

LAB2/

Program.cs — точка входа, запуск трёх тестовых сценариев

LAB2.csproj — файл проекта

1.ChaseData.txt — входные данные (сценарий 1)

2.ChaseData.txt — входные данные (сценарий 2)

3.ChaseData.txt — входные данные (сценарий 3)





\### Классы



\- \*\*`Player`\*\* — игрок (кот или мышь). Хранит имя, позицию, состояние

&#x20; (`Playing`, `Winner`, `Loser`, `NotInGame`) и пройденное расстояние.

\- \*\*`Game`\*\* — управляет игрой: читает команды, обрабатывает ходы, выводит

&#x20; состояние в `PursuitLog.txt`.



\## Формат входных данных



Файл `ChaseData.txt`:



1\. Первая строка — размер поля `N` (целое положительное число, ≤ 10000).

2\. Далее — команды, по одной на строку:

&#x20;  - `M <число>` — задать начальную позицию мыши или сделать ход.

&#x20;  - `C <число>` — задать начальную позицию кота или сделать ход.

&#x20;  - `P` — вывести текущее состояние игры в лог.



Первое появление `M` или `C` задаёт начальную позицию (это \*\*не\*\* ход,

расстояние не увеличивается). Все последующие — обычные ходы.



\## Формат выходных данных



Файл `PursuitLog.txt`:

{

Cat and Mouse



Cat Mouse Distance



?? 2

6 11 5

12 11 1



Distance traveled: Mouse Cat

28 7



Mouse caught at: 11

}



Если игрок ещё не в игре — вместо его позиции выводится `??`.
