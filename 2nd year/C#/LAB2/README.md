# LAB2 — Cat and Mouse

Игра «Кошки-мышки» на C#. Кот и мышь ходят по кругу из N клеток.
Если кот попадает в ту же клетку, что и мышь — мышь поймана.

## Как это работает

- Поле — это круг из клеток с номерами от 1 до N.
- Игрок не может выйти за пределы поля: если шаг «вылезает», он оборачивается на другую сторону.
- Первое появление игрока задаёт его начальную позицию (это не считается ходом).
- Все следующие команды — обычные ходы.

## Команды во входном файле

- `M <число>` — задать начальную позицию мыши или сделать ход
- `C <число>` — задать начальную позицию кота или сделать ход
- `P` — вывести текущее состояние в лог

## Файлы проекта

**LAB2:**
- `Program.cs` — точка входа, запускает три сценария
- `Game.cs` — логика игры: чтение команд, обработка ходов, запись лога
- `Player.cs` — игрок (кот или мышь): позиция, состояние, пройденный путь
- `GameFiles.cs` — пути к входному и выходному файлам
- `GameEnums.cs` — перечисления `State` и `GameState`
- `1.ChaseData.txt`, `2.ChaseData.txt`, `3.ChaseData.txt` — примеры входных данных

**LAB2.Tests:**
- `GameTests.cs` — тесты для класса `Game`
- `PlayerTests.cs` — тесты для класса `Player`
- `TestCase.cs` — описание одного тестового случая
- `TestRunner.cs` — запускает игру по тестовому случаю и возвращает лог

## Запуск
cd LAB2
dotnet run
Создаст файлы `1.PursuitLog.txt`, `2.PursuitLog.txt`, `3.PursuitLog.txt` в папке `bin/Debug/net10.0/`.

## Что тестируется

**PlayerTests** — юнит-тесты класса `Player`:
- нормализация позиции (обёртка поля через край)
- начальное состояние игрока
- накопление пройденного пути
- работа с отрицательными числами

**GameTests** — сценарии игры:
- три сценария из задания (`1.ChaseData.txt`, `2.ChaseData.txt`, `3.ChaseData.txt`)
- кот встаёт на мышь сразу
- начальное состояние — оба игрока вне игры
